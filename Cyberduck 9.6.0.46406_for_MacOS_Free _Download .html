What's New in Cyberduck 9.6.0.46406?

Cyberduck 9.6.0 was released on November 5, 2026. This release introduces several improvements related to cloud connectivity, authentication and file transfers.

AWS Console Browser Sign-In

The update introduces browser-based sign-in support for Amazon S3 connections using AWS Console authentication.

Microsoft Entra ID Support

Users can now authenticate with Microsoft Entra ID when connecting to supported Azure services.

Improved SFTP Support

The release adds ProxyCommand support through ssh_config and support for an SFTP copy extension.

Client-Side Checksum Verification

Uploads to supported storage providers can benefit from client-side checksum verification to help confirm file integrity.

Additional Improvements

The update also includes improvements for virtual folders, bucket creation and several connection and file management issues.
