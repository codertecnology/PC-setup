Supported Image Formats

AVS Image Converter supports several common image formats and selected additional graphics formats. Depending on the version, supported formats include:

  • JPEG / JPG: Commonly used for photographs and web images.
  • PNG: Useful for graphics and images requiring transparency.
  • BMP: A bitmap image format used in various applications.
  • GIF: Supports animated image creation.
  • TIFF: Commonly used for high-quality image storage.
  • TGA and RAS: Additional graphics formats supported by the application.
  • PDF: Allows supported image conversion workflows involving PDF output.
  • Camera RAW Formats: Selected formats such as DNG, NEF, CR2 and other camera formats may be supported.
Note: Available import and export formats can differ. Check the official documentation for the exact format support in your installed version.
